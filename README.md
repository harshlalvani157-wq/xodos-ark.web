In short the Android OS only allows a limited number of child processes to run at any one time, 30+ processes.
If that limit is exceeded then the OS activates a background service called the phantom process killer.
It finds the parent processes (main app) that are creating all of the child process that are exceeding the limit and terminate the parent process, which shuts the main application (xodos) down.

The OS has the phantom process killer backgroumd service to limit the activity in backgroumd so not to slow process down, which makes devices act slow.
