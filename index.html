Before You Board

Two settings, checked once

Most failed installs trace back to one of these two — not a bad download, not a bad device.

Disable child process restrictions

DISABLE THE PHANTOM PROCESER KILLER TO RUN THE LINUX ON YOUR DEVICE WITHOUT ANY CRASH. Want to learn more about that how to do that then clcik here

Resets itself if Developer Options ever gets switched off and back on — recheck it before your next install session.

Grant only what's asked

When the app requests file/storage permission, grant that dialog as shown. Don't separately enable a broader "manage all files" toggle beyond what it actually asks for — that exposes Android's own system-adjacent paths, and an accidental delete there risks the OS itself, not just app data.

The standard prompt is enough. More access isn't a shortcut, it's a bigger blast radius.

One thing to know

Some banking/government apps refuse to open while Developer Options is on. There's no reliable in-app bypass for this right now — the safest option is manually switching Developer Options off before opening those apps, then back on before your next install session.

Getting Started

Board the Ark in minutes

Install the APK, pick a distro, and launch your first desktop session.

1

Install the APK

Grab the latest release from GitHub, install it, and grant storage permissions. Requires Android 10 (API 29)+.

2

Pick your distro & update

Select a distribution, start the container, and update package sources:

apt update && apt upgrade -y
3

Install your desktop environment

Choose an efficient desktop interface such as XFCE4 or Openbox for maximum smoothness:

apt install xfce4 xfce4-terminal -y
4

Launch the session

Start your display server and launch the desktop session:

export DISPLAY=:0 && dbus-launch --exit-with-session xfce4-session &
