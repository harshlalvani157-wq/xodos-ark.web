THE BASICS

What is the native environment?

A Linux-like command-line workspace inside Ark, with its own package setup and custom package repository.

01 · The terminal

Type commands to manage your environment. The prompt is where you enter an instruction and press Enter to run it.

$ apt --help

02 · The package manager

apt is used to find, install, and remove packages made available to your environment.

$ apt install firefox

03 · The custom repository

Ark is configured to use its package source. Package availability depends on the repository and the environment version.

$ apt search firefox

04 · No Android root required

The native environment runs within Ark's app-managed environment. It is separate from Android's system package manager.

Android ≠ apt environment
COMMAND CHEATSHEET

Commands you will use

Use these as a starting point. Replace the example package name with a package that exists in Ark's repository.

Update package lists

Refreshes the package information available to the environment.

apt update

Search for a package

Checks whether a package name is listed in the configured repository.

apt search firefox

Install a package

Installs the named package and any required dependencies.

apt install firefox

Remove a package

Removes an installed package. Read the confirmation prompt in your actual terminal before proceeding.

apt remove firefox

Show package information

Displays details for a package, if it is available.

apt show firefox

See apt help

Lists supported apt commands and usage information.

apt --help

YOUR FIRST INSTALL

Follow this simple flow

Open Native Environment in Ark

Launch the native environment from the Ark app and wait until its terminal prompt is ready.

Refresh package information

Run apt update so apt refreshes the package lists from the configured source.

Search before installing

Run apt search firefox (or another package name) to check whether it is available.

Install the package

Run apt install firefox. Review the packages and confirmation prompt shown by your real environment.

Launch and explore

After installation completes, use the package's documented launch command. Launch commands can differ between packages.

Note: This guide uses Firefox as an example. It does not guarantee Firefox is currently available in every Ark repository build. Check the real terminal's search result before installing. Avoid running commands copied from sources you do not trust.
